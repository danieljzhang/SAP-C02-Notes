# Concept Guides

Cross-cutting concept guides that complement the domain-organized service
notes. While the `Domain-*` folders go service by service, these guides group
related services into decision-oriented themes: how to choose between them,
what constraints matter, and where the classic exam traps hide.

All guides are independently written in original wording with fresh examples.
They do not reproduce flashcard text, practice questions, or copyrighted
material. Verify version-sensitive details against current AWS documentation.
