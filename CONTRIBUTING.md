# Contributing to SAP-C02-Notes

Contributions are welcome. Please follow these guidelines to keep the repository accurate and useful.

## Ground Rules

- All content must be based on official AWS documentation or the current SAP-C02 exam guide
- Do not reproduce actual exam questions or content from exam dumps
- Do not invent service behavior, quotas, pricing, or exam content
- Mark version-sensitive details and assumptions clearly

## How to Contribute

1. Fork the repository and create a feature branch
2. Follow the existing file naming convention: `ServiceName-General.md` or `ServiceName-DeepDive-Topic.md`
3. Place files in the correct domain folder based on the SAP-C02 exam guide
4. Use the prompt templates in `prompts.md` as a quality baseline
5. Submit a pull request with a clear description of what was added or changed

## Content Standards

- Use clear Markdown headings (`##`, `###`)
- Include architecture-level reasoning, not just feature lists
- Add original scenario-based examples — no copied exam questions
- Include exam tips and common traps
- Link to current official AWS documentation

## Reporting Issues

Open a GitHub Issue for:
- Technical inaccuracies
- Outdated service information
- Missing exam-relevant topics
- Broken links

## What Not to Do

- Do not submit AI-generated content without reviewing it for accuracy
- Do not add content outside the SAP-C02 exam scope
- Do not claim coverage percentages without a defined scoring method
